How Identra SSO works

Three steps from login page to authenticated session.

1

Your app embeds the Identra login screen

Your existing login page posts the submitted username and password to Identra's auth endpoint instead of handling credentials itself.

2

Identra connects to your organization's LDAP directory

Identra binds to your directory using a dedicated service account, then runs a search filter built from the submitted credentials to locate a matching directory entry:

filter = (&(uid={username})(userPassword={password}))

A non-empty result is treated as a match for that user's directory entry.

3

Session established

On a match, Identra hands your app a session and redirects the user to the authenticated area of your site.

Full configuration keys and supported directory versions are in the docs.
