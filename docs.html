Configuration reference

identra.conf

backend     = ldap
ldap_url    = ldap://127.0.0.1
base_dn     = ou=people,dc=example,dc=com
bind_dn     = uid=svc-webapp,ou=people,dc=example,dc=com
bind_pw     = <service account password>
auth_filter = (&(uid={username})(userPassword={password}))

auth_filter is evaluated against base_dn after binding as the service account named in bind_dn. Any result with one or more entries is treated as a successful login for that directory entry.
